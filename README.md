## 📋 Опис проєкту

Проєкт демонструє декомпозицію довгого монолітного методу (`LegacyProcessor.Process`) з високою цикломатичною складністю (CC=31, 92 рядки, 11 параметрів) на короткі, сфокусовані підпрограми із функціональною зв'язністю та слабким зчепленням.

Реалізовано:
1. Захисне програмування (Guard Clauses) для перевірки контрактів.
2. Патерн **Parameter Object** (`TotalRequest`, `ClientInfo`, `TotalResult`).
3. Дотримання принципу **Command-Query Separation (CQS)** та чистих функцій (усунено прямий `Console.WriteLine` із доменної логіки).
